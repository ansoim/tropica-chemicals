Workbook connection

Your source of truth.

This dashboard reads the latest values saved in the GitHub data file. When your Excel-to-GitHub automation updates that file, visitors see the updated names, sales, and target progress the next time they open or refresh the dashboard.

The dashboard reads data/sales.json. It does not sign in to SharePoint directly. The Power Automate flow still needs to update that GitHub file after Excel changes; until then, the page shows the most recently uploaded snapshot.

Workbook access stays inside your Microsoft 365 flow. This public site only shows the summary figures that the flow publishes.
